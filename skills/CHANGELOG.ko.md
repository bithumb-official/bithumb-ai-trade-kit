## [0.8.5] - 2026-06-08

### Added

- Bithumb Skills 모음 최초 공개 릴리스.
- `bithumb-market` — 시세, 캔들, 호가, 체결, 공지, 수수료 등 공개 마켓 데이터 조회.
- `bithumb-account` — 잔고, 거래 가능 정보, 지갑 및 출금 상태, API 키 정보 조회.
- `bithumb-trade` — 지정가, 시장가, 다건, TWAP 주문 등 현물 주문 생성, 취소, 조회.
- `bithumb-deposit` — 입금 주소, 입금 내역, 원화 입금 요청 관리.
- `bithumb-withdraw` — 출금, 출금 취소, 출금 내역, 수수료, 허용 주소 관리.
- `bithumb-system` — 연결, 인증, 감사 로그, 지원 기능 진단.
